# Validation : diamètre des mandrins de cintrage

## Endommagement de l’armature (tableau 8.1N a) ; 11.3(2))

HA20 : φ > 16 mm, 7 φ = **140 mm**. HA12 : 4 φ = **48 mm**. Mêmes valeurs dans
les deux générations.

## Béton dans la courbure, 2004 (8.1)

Crosse d’un HA20 en rive, plastifié : σ_sd = 500/1,15 = 434,78 MPa,
A_s = π × 20²/4 = 314,16 mm², F_bt = 136 591 N = **136,6 kN** ; enrobage 50 mm,
a_b = 50 + 10 = 60 mm ; C30/37, f_cd = 30/1,5 = 20 MPa.

φ_m,min = 136 591 × (1/60 + 1/40) / 20 = 136 591 × 0,041667 / 20 = **284,6 mm**,
soit 2,03 fois le mandrin de 140 mm.

C70/85 : f_cd plafonnée à 55/1,5 = 36,67 MPa, φ_m,min = **155,2 mm**.

HA12 intérieur, entraxe 150 mm (a_b = 75), plastifié : F_bt = 49,2 kN,
φ_m,min = 135,2 mm (non repris dans les tests).
