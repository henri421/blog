# Validation : profondeur d’appui des éléments préfabriqués

Poutre préfabriquée de 8 m sur corbeau, F_Ed = 400 kN, b_1 = 300 mm, C40/50,
longueur nette prévue 150 mm, profondeur nominale prévue 200 mm.

| | 2004 | 2023 |
|---|---:|---:|
| f_cd | 40/1,5 = 26,667 | 1 × 0,85 × 40/1,5 = 22,667 |
| Lit, f_Rd = min(15 ; 0,85 f_cd) | 15 | 15 |
| F_Ed/(b_1 f_Rd) | 400 000/(300 × 15) = 88,9 | 88,9 |
| a_1 (2004 : minimum 110 mm, tableau 10.2, σ_Ed/f_cd = 0,33) | **110,0** (taux 0,733) | **88,9** (taux 0,592) |
| Joint sec, f_Rd = 0,4 f_cd | 10,667 → **125,0** | 9,067 → **147,1** |

Nominale 2004 (10.6) : a_2 = 15, a_3 = 15, Δa_2 = 10 mm (valeurs lues dans les
tableaux 10.3 à 10.5), Δa_3 = 8000/2500 = 3,2 mm ;
a = 110 + 15 + 15 + √(10² + 3,2²) = 140 + 10,50 = **150,5 mm** (taux 0,752) ;
élément isolé : **170,5 mm**.
