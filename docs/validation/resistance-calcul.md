# Validation : résistance de calcul, MFA ou RFA (EN 1990)

Calcul à la main, $R = k\,X^q$, $k$ = 0,66, $X_k$ = 30, $\eta$ = 1, $\gamma$ = 1,5.

| $q$ | MFA $k\,(X_k/\gamma)^q$ | RFA $k\,X_k^q/\gamma$ |
|---|---|---|
| 1/3 | 0,66 × 20^(1/3) = 1,7915 | 0,66 × 30^(1/3)/1,5 = 1,3672 |
| 1 | 0,66 × 20 = 13,2 | 0,66 × 30/1,5 = 13,2 |

Pour $q$ = 1/3, l’écart vaut $\gamma^{1-q}$ = 1,5^(2/3) = 1,310.
